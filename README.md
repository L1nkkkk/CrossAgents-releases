# CrossAgents releases

Windows installers for **CrossAgents**, a hub where coding agents from different vendors work together: a strong model plans, cheaper models write the code, and you approve and land the result.

This repository holds only release builds. The source is private.

## Install

Download `CrossAgents-Setup-<version>.exe` from [Releases](../../releases/latest) and run it. It installs for the current user, with no administrator rights needed. The installer bundles the matching `crossagents.exe` hub.

The app updates itself: it downloads new versions from this repository in the background and installs them when you quit.

The installer is not code-signed yet, so Windows SmartScreen may warn about it the first time you run it.

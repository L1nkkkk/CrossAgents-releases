## Get started

1. Run `CrossAgents-Setup-<version>.exe`
2. Sign in to an agent:

   | Agent | |
   |---|---|
   | Claude Code | `claude auth login` |
   | Codex | `codex login` |
   | WorkBuddy | `npm install -g @tencent-ai/codebuddy-code`, then `/login` inside `codebuddy` |

<sub>Per-user install, updates itself. Not code-signed yet: if SmartScreen warns, choose "More info → Run anyway". The source is private; this repository holds release builds only. All footage shows demo data.</sub>
